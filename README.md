# 文献库

[English](README.en.md) · 简体中文

本地优先、文件系统可读、支持动态标签和人工智能分析的 macOS 经济学文献管理器。

## 隐私与联网

应用不设自有账户、同步、广告或行为分析服务。文献与资料库数据默认保留在本机；联网功能仅在用户主动使用时调用第三方服务。人工智能分析、智能检索与元数据核对可能传输文献内容节选或书目信息。

使用前请阅读完整的[隐私说明](PRIVACY.md)。请不要将不应发送给第三方服务的文献用于联网分析或智能检索。

想了解每项能力的实现、数据流与容错设计，请阅读[实现说明](ARCHITECTURE.md)。

## 主要能力

- 选择本地资料库目录并保存安全作用域书签
- 拖入单个或批量 PDF，源文件始终保持不变
- 持久导入与移动事务，支持失败回滚和崩溃后恢复
- 提取题名、作者、页数、年份、标注和正文
- 使用 SHA-256、DOI、NBER、SSRN、arXiv、RePEc 和文本指纹查重
- 支持多个 PDF 版本、首选版本、合并和拆分
- 自动使用 Crossref 核对元数据，并显示 OpenAlex 期刊评价
- 动态分类、标签、智能列表、组合搜索和批量操作
- 阅读项目及项目内优先级、已读状态和独立排序
- 单篇 BibTeX 在线核对，以及多篇本地或在线批量导出
- Gemini 结构化研究卡、证据页码校验、取消、重试和费用预算
- Gemini 分章精读笔记，支持缓存、检查点、中断后继续和费用估算
- 普通笔记与精读笔记保存在 PDF 旁边，永不覆盖现有文件
- 自动健康检查，可通过 SHA-256 重新定位被移动的 PDF
- 可恢复清单、历史清单备份和数据库损坏隔离恢复
- 使用系统默认或用户指定的外部 PDF 阅读器

## 资料库结构

```text
资料库根目录/
├── Labor/
│   └── 2024/
│       └── Doe - 2024 - Paper Title/
│           ├── Doe - 2024 - Paper Title.pdf
│           ├── Doe - 2024 - Paper Title.md
│           ├── Doe - 2024 - Paper Title.assets/
│           ├── Doe - 2024 - Paper Title-精读笔记.md
│           └── Doe - 2024 - Paper Title-精读笔记.assets/
├── Uncategorized/
│   └── Unknown Year/
└── .paperlib/
    ├── library.json
    ├── manifest.json
    ├── imports/
    ├── operations/
    └── backups/
```

未获得可信题名、作者和年份时，PDF 保留原文件名并进入 `Uncategorized/Unknown Year/`。获得人工确认或可信网络核对结果后，应用会按作者、年份和题名整理文件夹。

## 搜索、项目与导出

搜索可限定题名、作者、书目信息、研究内容、标识符或文件字段，支持全部关键词、任意关键词和完整词组。年份、待检查、已分析、有摘要、有标注、多版本和缺少 DOI 也可作为组合条件。

智能搜索会在当前项目、分类和标签范围内融合 BM25、语义向量和书目信息排名，再使用 Qwen3.7 重排。候选先按文献合并，避免长文献的多个段落挤占其他文章；设置中可选择快速、平衡或深度检索，并将最终结果上限设为 5、10 或 20 篇。

项目只记录阅读组织关系，不会移动或复制 PDF。同一篇文献可属于多个项目。

批量 BibTeX 导出提供两种模式：

- “使用资料库记录”只导出已确认且无待处理问题的条目。
- “在线核验”使用 DOI、Crossref 和 Semantic Scholar 查找记录，不一致时集中显示差异。

无效条目会被跳过并在完成摘要中说明，不会阻止其他条目导出。

## 人工智能设置

在应用设置中填写 Gemini API 密钥、快速模型名称、每月预算和当前令牌价格。快速模型默认为 `gemini-3.5-flash-lite`，精读笔记固定使用 `gemini-3.1-pro-preview`。密钥保存在应用沙盒的本地私有文件中，文件权限仅允许当前用户读写。

默认情况下，超过 200 页的文献只上传前 60 页进行自动分析；也可在设置中改为跳过自动分析。单份用于研究卡的 PDF 上限为 50 MB。请根据供应商公告更新价格设置。

人工智能请求失败不会影响 PDF 导入、搜索、归档或外部打开。精读笔记会保留检查点，可从下一部分继续。

## 备份、恢复与健康检查

应用启动时会恢复未完成的导入和文件移动，检查已登记的 PDF，并尝试按 SHA-256 自动重新定位。在“设置—资料库维护”中可手动重新检查，查看已检查、已重新定位、已修复和仍然缺失的数量。缺失文件会进入“有问题”列表。

`.paperlib/manifest.json` 记录文献、分类、标签、项目、文件版本和分析状态，并保留最近十份历史备份。数据库损坏时，原数据库及日志会先被安全隔离，新数据库再尝试从清单恢复。

## 构建与测试

- Xcode 26.6 或兼容版本
- 最低运行系统为 macOS 14

打开 `PaperLibrary.xcodeproj`，选择 `PaperLibrary` 方案运行。

命令行单元测试：

```sh
/Applications/Xcode.app/Contents/Developer/usr/bin/xcodebuild \
  -project PaperLibrary.xcodeproj \
  -scheme PaperLibrary \
  -destination 'platform=macOS' \
  -skipPackagePluginValidation \
  -skipMacroValidation \
  -only-testing:PaperLibraryTests \
  test
```

智能搜索的向量生成和候选重排均使用北京区百炼 Qwen3.7；应用不再包含本地大模型运行时或模型下载依赖。已生成的向量可在三档搜索深度间复用，调整结果数量不需要重建索引。

测试覆盖导入与回滚、批量文件安全、移动事务恢复、查重、文件命名、搜索、BibTeX、人工智能结果、精读检查点、费用估算、可恢复清单和资料库健康检查。

本公开仓库不包含个人签名身份、发布脚本或已签名安装包。需要分发应用时，请由分发者自行完成签名、校验与发布，并确保不将证书、私钥或本机配置提交到仓库。
