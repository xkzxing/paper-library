# Contributing

[简体中文](CONTRIBUTING.md) · English

Bug reports, feature requests, and improvements are welcome.

- Do not include original papers, API keys, certificates, machine-specific paths, or build products.
- Keep changes focused and small, and include relevant tests.
- If a change affects network access, paper-content transfers, or key storage, update the privacy notice as well.
- Do not post API keys or reproducible private data when reporting a security issue. Use a private contact channel provided by the repository maintainers.
